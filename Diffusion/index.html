Denoising Diffusion Probabilistic Models

The Big Picture

A Denoising Diffusion Probabilistic Model (DDPM) is a latent-variable generative model that can be seen as a special case of a hierarchical VAE. Its encoder is not learned: it slowly destroys a data point by adding Gaussian noise over many steps until only noise is left. Its decoder is learned: it undoes the corruption one small step at a time.

\(x_0\) data
→
\(x_1\) noisy data
→
\(x_2\) noisy-noisy data
→ ⋯ →
\(x_T\) “noise only”

Forward (encoding) process: fixed, adds noise. Reverse (decoding) process \(x_T\to x_{T-1}\to\cdots\to x_0\): learned, removes noise.

Once the reverse process is learned, generating a new sample is easy: draw pure noise \(x_T\sim\mathcal{N}(0,I)\) and denoise it step by step until a data point \(x_0\) appears.

1. DDPM as a Special Case of a Hierarchical VAE

Suppose we are given a dataset

\[ \mathcal{D} = \{x^{(i)}\}_{i=1}^{N}, \qquad x^{(i)} \sim p_X(x) \quad \text{(data distribution)}. \]

The goal of generative AI is to learn to sample from \(p_X\). DDPMs are latent-variable generative models that can be seen as a special case of hierarchical VAEs.

Recall: the VAE

In a VAE there is a single latent space. The encoder maps data to a latent variable and the decoder maps it back:

\(x\) data
→
\(z\) latent
→
\(\hat{x}\) data

Encoder \(q_\phi(z\mid x)\)  ·  Decoder \(p_\theta(x\mid z)\)

Hierarchical VAE

In a hierarchical VAE (HVAE) there are multiple latent spaces, stacked one after another:

\[ \underbrace{x \to z_1 \to z_2 \to \cdots \to z_T}_{\text{encoding}} \qquad\qquad \underbrace{z_T \to z_{T-1} \to \cdots \to z_1 \to x}_{\text{decoding}} \]

What makes a DDPM special

A DDPM is an HVAE with the following properties:

  1. There are multiple latent spaces \(z_1, z_2, \ldots, z_T\).
  2. The dimensionality of every latent space equals that of the data space: \(\dim(z_t) = \dim(x)\) for all \(t\).
  3. The encoding procedure is fixed and not learnable, unlike in a VAE.
VAE DDPM
Encoder \(q_\phi(z\mid x)\) is a neural network that is learned \(q(z\mid x)\) is fixed and not learnable
What is learned Both encoding and decoding Only decoding
Latent dimension Usually much smaller than \(\dim(x)\) Same as \(\dim(x)\)
Number of latent spaces One \(T\)

2. DDPM Notation

The DDPM literature uses a slightly different notation from the VAE:

Data

\(x_0\): a data point

Previously written as \(x\).

Latents

\(x_1, x_2, \ldots, x_T\): latent vectors

Previously written as \(z_1, z_2, \ldots, z_T\).

Don't be confused: here the subscript is a time step, not a data index. \(x_1, x_2, \ldots\) are successive noisy versions of the same data point \(x_0\), not different points in the dataset. We also write \(x_{1:T} = (x_1, \ldots, x_T)\) and \(x_{0:T} = (x_0, x_1, \ldots, x_T)\).

3. The Encoding / Forward Process

\[ \underbrace{x_0}_{\text{data point}} \;\longrightarrow\; \underbrace{x_1 \longrightarrow x_2 \longrightarrow \cdots \longrightarrow x_T}_{\text{latent vectors corresponding to } x_0} \]

All of these live in the same space: \(\dim(x_t) = \dim(x_0) = \mathbb{R}^d\) for all \(t\). The number of steps \(T\) is a hyperparameter.

3.1 Defining the forward process

The forward process mixes the previous state with a bit of fresh Gaussian noise at each step:

\[ \begin{aligned} x_1 &= \sqrt{\alpha_1}\,x_0 + \sqrt{1-\alpha_1}\,\epsilon_1, &\epsilon_1 &\sim \mathcal{N}(0,I) \\ x_2 &= \sqrt{\alpha_2}\,x_1 + \sqrt{1-\alpha_2}\,\epsilon_2, &\epsilon_2 &\sim \mathcal{N}(0,I) \\ &\;\;\vdots \\ x_t &= \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon_t, &\epsilon_t &\sim \mathcal{N}(0,I) \end{aligned} \]

where \(\alpha_1, \ldots, \alpha_T \in [0,1]\) are fixed scalars. Nothing here is learned.

Forward process
\[ \boxed{ x_t = \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon_t, \qquad \epsilon_t \sim \mathcal{N}(0,I) } \tag{1} \]
\(\sqrt{\alpha_1}\,x_0\) scaled image
+
\(\sqrt{1-\alpha_1}\,\epsilon_1\) noise
→
\(x_1\) slightly noisy
→ ⋯ →
\(x_T\) pure noise

Data → add noise → noisy data → add noise → noisy-noisy data → ⋯ → “noise only”

3.2 The forward process is a Markov chain

Eq. (1) defines a first-order Markov chain: a sequence of random variables \(x_0, x_1, \ldots, x_T\) such that each one depends only on the one immediately before it,

\[ q(x_t \mid x_{t-1}, x_{t-2}, \ldots, x_0) = q(x_t \mid x_{t-1}). \]

So the forward process can be described as a series of conditional distributions on the latent variables. Since \(x_t\) is a scaled \(x_{t-1}\) plus independent Gaussian noise,

Conditional forward / encoding distributions
\[ \boxed{ q(x_t \mid x_{t-1}) = \mathcal{N}\!\left(x_t;\ \sqrt{\alpha_t}\,x_{t-1},\ (1-\alpha_t)\,I\right) } \]

The noise level is chosen so that, after many steps, all information about \(x_0\) is gone and

\[ q(x_T) \approx \mathcal{N}(0, I), \]

the stationary distribution of the Markov chain.

4. The Decoding / Reverse Process: Defining the Model

The model is defined through a decoding distribution over the data and all the latents:

\[ p_\theta(x_{0:T}) = p_\theta(\underbrace{x_0}_{\text{data}},\ \underbrace{x_1, \ldots, x_T}_{\text{latent variables}}) = p(x_T)\prod_{t=1}^{T} p_\theta(x_{t-1}\mid x_t), \]

where each reverse step is Gaussian:

Reverse / decoding transitions
\[ \boxed{ p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\left(x_{t-1};\ \mu_\theta(x_t),\ \Sigma_\theta(x_t)\right), \qquad p(x_T) = \mathcal{N}(0, I) } \]

\(p_\theta\) defines a latent-variable model with multiple latent variables, just like a VAE defines \(p_\theta(x, z)\), the joint distribution between the data and the latent variables.

Where does this form come from? The model distribution \(p_\theta\) of a DDPM arises from making the same first-order Markovian assumption in the reverse direction, with Gaussian transitions that contain learnable parameters. The mean \(\mu_\theta(x_t)\) and covariance \(\Sigma_\theta(x_t)\) are learned via the ELBO.
\(x_T\) \(\mathcal{N}(0,I)\)
→
\(p_\theta(x_{T-1}\mid x_T)\) learned
→ ⋯ →
\(p_\theta(x_0\mid x_1)\) learned
→
\(x_0\) data

5. ELBO Optimization to Learn the Decoding Parameters

Recall that in a VAE, we lower-bound the log-likelihood by introducing the encoder \(q(z\mid x)\):

\[ \log p_\theta(x) = \log \int p_\theta(x, z)\,dz \;\ge\; \underbrace{ \mathbb{E}_{q(z\mid x)} \left[ \log \frac{p_\theta(x, z)}{q(z\mid x)} \right] }_{J_\theta(q)\ :\ \text{Evidence Lower Bound (ELBO)}} \]

A DDPM is the same construction with \(z\) replaced by all the latents \(x_{1:T}\), and the encoder replaced by the fixed forward process:

ELBO for a DDPM
\[ \boxed{ J_\theta(q) = \mathbb{E}_{q(x_{1:T}\mid x_0)} \left[ \log \frac{p_\theta(x_0, x_1, \ldots, x_T)}{q(x_1, \ldots, x_T\mid x_0)} \right] = \mathbb{E}_{q(x_{1:T}\mid x_0)} \left[ \log \frac{p_\theta(x_{0:T})}{q(x_{1:T}\mid x_0)} \right] } \]

6. Optimizing the ELBO for a DDPM

6.1 Factorizing the numerator and denominator

The numerator comes straight from the model definition:

\[ p_\theta(x_{0:T}) = p(x_T)\prod_{t=1}^{T} p_\theta(x_{t-1}\mid x_t), \qquad p(x_T) = \mathcal{N}(0, I). \]

Similarly, the denominator follows from the chain rule of probability:

\[ \begin{aligned} q(x_{1:T}\mid x_0) &= q(x_1\mid x_0)\, q(x_2\mid x_1, x_0)\, q(x_3\mid x_2, x_1, x_0) \cdots q(x_T\mid x_{T-1}, \ldots, x_0) \\ &= \prod_{t=1}^{T} q(x_t\mid x_{t-1}) \qquad \text{(the forward / encoding process is first-order Markov)}. \end{aligned} \]

Therefore

\[ J_\theta(q) = \mathbb{E}_{q} \log \left[ \frac{p(x_T)\prod_{t=1}^{T} p_\theta(x_{t-1}\mid x_t)} {\prod_{t=1}^{T} q(x_t\mid x_{t-1})} \right]. \]

Consider the term inside the expectation. Pulling out the \(t=1\) factors,

\[ \begin{aligned} \log \left[ \frac{p(x_T)\prod_{t=1}^{T} p_\theta(x_{t-1}\mid x_t)} {\prod_{t=1}^{T} q(x_t\mid x_{t-1})} \right] &= \log \frac{p(x_T)\,p_\theta(x_0\mid x_1)\prod_{t=2}^{T} p_\theta(x_{t-1}\mid x_t)} {q(x_1\mid x_0)\prod_{t=2}^{T} q(x_t\mid x_{t-1})} \\[6pt] &= \log \frac{p(x_T)\,p_\theta(x_0\mid x_1)}{q(x_1\mid x_0)} + \log \prod_{t=2}^{T} \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_t\mid x_{t-1})}. \end{aligned} \]

6.2 Rewriting the denominator with Bayes' rule

Consider the denominator in the second term. Because the forward process is first-order Markov, conditioning additionally on \(x_0\) changes nothing, and we can then apply Bayes' rule with three random variables:

\[ \begin{aligned} q(x_t\mid x_{t-1}) &= q(x_t\mid x_{t-1}, x_0) && \text{(1st-order Markov)} \\[4pt] &= \frac{q(x_{t-1}\mid x_t, x_0)\,q(x_t\mid x_0)}{q(x_{t-1}\mid x_0)} && \text{(Bayes' rule with 3 RVs)}. \end{aligned} \]
What is \(q(x_{t-1}\mid x_t, x_0)\)? It is the distribution of \(x_{t-1}\), given that the encoding process has landed at \(x_t\) at time \(t\), starting from \(x_0\). It describes how to take one step backwards when we know where the chain started and where it currently is.

Plugging this expression into the ELBO,

\[ \begin{aligned} &\log \frac{p(x_T)\,p_\theta(x_0\mid x_1)}{q(x_1\mid x_0)} + \log \prod_{t=2}^{T} \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_t\mid x_{t-1})} \\[6pt] &= \log \frac{p(x_T)\,p_\theta(x_0\mid x_1)}{q(x_1\mid x_0)} + \log \prod_{t=2}^{T} \frac{p_\theta(x_{t-1}\mid x_t)\,q(x_{t-1}\mid x_0)} {q(x_{t-1}\mid x_t, x_0)\,q(x_t\mid x_0)} \\[6pt] &= \log \frac{p(x_T)\,p_\theta(x_0\mid x_1)}{q(x_1\mid x_0)} + \log \prod_{t=2}^{T} \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_{t-1}\mid x_t, x_0)} + \log \prod_{t=2}^{T} \frac{q(x_{t-1}\mid x_0)}{q(x_t\mid x_0)}. \end{aligned} \]

6.3 The telescoping product

The last product telescopes: every numerator cancels the previous denominator,

\[ \log \prod_{t=2}^{T} \frac{q(x_{t-1}\mid x_0)}{q(x_t\mid x_0)} = \log \frac{q(x_1\mid x_0)\,\cancel{q(x_2\mid x_0)}\cdots} {\cancel{q(x_2\mid x_0)}\,\cancel{q(x_3\mid x_0)}\cdots q(x_T\mid x_0)} = \log \frac{q(x_1\mid x_0)}{q(x_T\mid x_0)}. \]

The surviving \(q(x_1\mid x_0)\) now cancels with the denominator of the first term:

\[ \begin{aligned} &= \log \frac{p(x_T)\,p_\theta(x_0\mid x_1)}{\cancel{q(x_1\mid x_0)}} + \log \prod_{t=2}^{T} \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_{t-1}\mid x_t, x_0)} + \log \frac{\cancel{q(x_1\mid x_0)}}{q(x_T\mid x_0)} \\[6pt] &= \underbrace{ \log p_\theta(x_0\mid x_1) + \log \frac{p(x_T)}{q(x_T\mid x_0)} + \sum_{t=2}^{T} \log \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_{t-1}\mid x_t, x_0)} }_{\text{(Term)}}. \end{aligned} \]

6.4 Bringing in the outer expectation

We now take \(\mathbb{E}_{q(x_{1:T}\mid x_0)}\left[\text{Term}\right]\). Since the sub-terms in (Term) depend only on subsets of \(x_{1:T}\), the outer expectation can be written appropriately, each over only the variables it involves:

\[ J_\theta(q) = \mathbb{E}_{q(x_1\mid x_0)} \log p_\theta(x_0\mid x_1) + \mathbb{E}_{q(x_T\mid x_0)} \log \frac{p(x_T)}{q(x_T\mid x_0)} + \sum_{t=2}^{T} \mathbb{E}_{q(x_{t-1}, x_t\mid x_0)} \log \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_{t-1}\mid x_t, x_0)}. \]

For the last term, use the property of conditional expectation to split the joint expectation into two nested ones:

\[ \mathbb{E}_{q(x_{t-1}, x_t\mid x_0)}\left[\,\cdot\,\right] = \mathbb{E}_{q(x_t\mid x_0)} \; \mathbb{E}_{q(x_{t-1}\mid x_t, x_0)} \left[\,\cdot\,\right]. \]

Rewriting the ELBO with this property, each inner expectation of a log ratio is a negative KL divergence:

\[ \begin{aligned} J_\theta(q) &= \mathbb{E}_{q(x_1\mid x_0)} \log p_\theta(x_0\mid x_1) + \mathbb{E}_{q(x_T\mid x_0)} \log \frac{p(x_T)}{q(x_T\mid x_0)} \\ &\quad+ \sum_{t=2}^{T} \mathbb{E}_{q(x_t\mid x_0)} \mathbb{E}_{q(x_{t-1}\mid x_t, x_0)} \left[ \log \frac{p_\theta(x_{t-1}\mid x_t)}{q(x_{t-1}\mid x_t, x_0)} \right]. \end{aligned} \]
The DDPM ELBO
\[ \boxed{ \begin{aligned} J_\theta(q) =\;& \mathbb{E}_{q(x_1\mid x_0)} \log p_\theta(x_0\mid x_1) - D_{\mathrm{KL}}\!\left(q(x_T\mid x_0)\,\|\,p(x_T)\right) \\ &- \sum_{t=2}^{T} \mathbb{E}_{q(x_t\mid x_0)} \left[ D_{\mathrm{KL}}\!\left( q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t) \right) \right] \end{aligned} } \]

7. The Three Terms of the DDPM Objective

(i) Reconstruction term

\[ \mathbb{E}_{q(x_1\mid x_0)} \log p_\theta(x_0\mid x_1) \]

How well the last decoding step recovers the data from the first latent, exactly like the reconstruction term in a VAE.

(ii) Prior matching term

\[ D_{\mathrm{KL}}\!\left(q(x_T\mid x_0)\,\|\,p(x_T)\right) \]

Independent of \(\theta\). Both distributions are fixed, so this term can be dropped from the optimization.

(iii) Denoising matching term

\[ \sum_{t=2}^{T} \mathbb{E}_{q(x_t\mid x_0)} D_{\mathrm{KL}}\!\left( q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t) \right) \]

Also called the consistency term. It matches the learnable denoising step to the “known” one.

\(q(x_{t-1}\mid x_t, x_0)\) “known” denoising
⟷
\(p_\theta(x_{t-1}\mid x_t)\) learnable denoising

The KL in the denoising matching term pulls the learned reverse step towards the true reverse step, which is available because it gets to see \(x_0\).

Objective: \[ \theta^* = \arg\max_\theta\ J_\theta(q) \qquad \text{(ELBO)}. \] To actually compute the denoising matching term, we need the distribution \(q(x_{t-1}\mid x_t, x_0)\) in closed form. That is the job of the next two sections.

8. Estimating the KL: A Closed Form for \(q(x_t\mid x_0)\)

To compute \(q(x_{t-1}\mid x_t, x_0)\), we use Bayes' rule again:

\[ q(x_{t-1}\mid x_t, x_0) = \frac{q(x_t\mid x_{t-1}, x_0)\;q(x_{t-1}\mid x_0)}{q(x_t\mid x_0)} = \frac{q(x_t\mid x_{t-1})\;q(x_{t-1}\mid x_0)}{q(x_t\mid x_0)}. \]

We already know one of the three pieces:

\[ q(x_t\mid x_{t-1}) = \mathcal{N}\!\left(x_t;\ \sqrt{\alpha_t}\,x_{t-1},\ (1-\alpha_t)\,I\right). \]

The other two are of the form \(q(x_t\mid x_0)\): the distribution of \(x_t\) given the starting point, after \(t\) noising steps. It can be obtained by unrolling the recursion.

8.1 Unrolling the recursion

We have

\[ \begin{aligned} x_t &= \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon_{t-1}, && \epsilon_{t-1} \sim \mathcal{N}(0, I) \\[4pt] &= \sqrt{\alpha_t} \left( \sqrt{\alpha_{t-1}}\,x_{t-2} + \sqrt{1-\alpha_{t-1}}\,\epsilon_{t-2} \right) + \sqrt{1-\alpha_t}\,\epsilon_{t-1}, && \epsilon_{t-2} \sim \mathcal{N}(0, I) \\[4pt] &= \sqrt{\alpha_t\alpha_{t-1}}\,x_{t-2} + \underbrace{ \sqrt{\alpha_t - \alpha_t\alpha_{t-1}}\,\epsilon_{t-2} + \sqrt{1-\alpha_t}\,\epsilon_{t-1} }_{T_2}. \end{aligned} \]

Consider \(T_2 = a\,\epsilon_1 + b\,\epsilon_2\), with \(\epsilon_1, \epsilon_2 \overset{\text{iid}}{\sim} \mathcal{N}(0, I)\). \(T_2\) is a linear combination of two independent normal random variables, and therefore it is another Gaussian random variable. Its variances add:

\[ a^2 + b^2 = (\alpha_t - \alpha_t\alpha_{t-1}) + (1-\alpha_t) = 1 - \alpha_t\alpha_{t-1} \quad\Longrightarrow\quad T_2 = \epsilon^* \sim \mathcal{N}\!\left(0,\ (1-\alpha_t\alpha_{t-1})\,I\right). \]

So two steps of the chain collapse into one:

\[ x_t = \sqrt{\alpha_t\alpha_{t-1}}\;x_{t-2} + \sqrt{1-\alpha_t\alpha_{t-1}}\;\bar\epsilon_{t-2}, \qquad \bar\epsilon_{t-2} \sim \mathcal{N}(0, I). \]

Continuing the recursion all the way to \(x_0\),

\[ x_t = \sqrt{\alpha_t\alpha_{t-1}\cdots\alpha_1}\;x_0 + \sqrt{1-\alpha_t\alpha_{t-1}\cdots\alpha_1}\;\epsilon, \qquad \epsilon \sim \mathcal{N}(0, I). \]

Defining the cumulative product \(\bar\alpha_t = \prod_{i=1}^{t}\alpha_i\),

Jumping directly from \(x_0\) to \(x_t\)
\[ \boxed{ x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon, \qquad q(x_t\mid x_0) = \mathcal{N}\!\left(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)\,I\right) } \]
Why this matters: the latent at any time \(t\) can be obtained directly from the data \(x_0\), without hopping through \(t\) steps. This makes training cheap: to get a noisy \(x_t\), we just sample one \(\epsilon\).

9. The Known Denoising Distribution \(q(x_{t-1}\mid x_t, x_0)\)

Getting back to the consistency term, all three distributions in Bayes' rule are now Gaussians that we know:

\[ \begin{aligned} q(x_t\mid x_{t-1}) &= \mathcal{N}\!\left(x_t;\ \sqrt{\alpha_t}\,x_{t-1},\ (1-\alpha_t)\,I\right), \\ q(x_t\mid x_0) &= \mathcal{N}\!\left(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)\,I\right), \\ q(x_{t-1}\mid x_0) &= \mathcal{N}\!\left(x_{t-1};\ \sqrt{\bar\alpha_{t-1}}\,x_0,\ (1-\bar\alpha_{t-1})\,I\right). \end{aligned} \]

Substituting the Gaussian densities,

\[ \begin{aligned} q(x_{t-1}\mid x_t, x_0) &\propto \frac{ \exp\!\left[-\dfrac{\|x_t - \sqrt{\alpha_t}\,x_{t-1}\|_2^2}{2(1-\alpha_t)}\right] \exp\!\left[-\dfrac{\|x_{t-1} - \sqrt{\bar\alpha_{t-1}}\,x_0\|_2^2}{2(1-\bar\alpha_{t-1})}\right] }{ \exp\!\left[-\dfrac{\|x_t - \sqrt{\bar\alpha_t}\,x_0\|_2^2}{2(1-\bar\alpha_t)}\right] } \\[8pt] &\propto \exp\!\left[-\frac{\|x_{t-1} - \mu_q\|_2^2}{2\sigma_q^2}\right], \end{aligned} \]

where the last line is obtained via the completion of the square method in \(x_{t-1}\). The exponent is quadratic in \(x_{t-1}\), so the result is again Gaussian:

The known denoising posterior
\[ \boxed{ q(x_{t-1}\mid x_t, x_0) = \mathcal{N}\!\left(x_{t-1};\ \mu_q(x_t, x_0),\ \Sigma_q\right) } \]

where

\[ \mu_q(x_t, x_0) = \frac{\sqrt{\alpha_t}\,(1-\bar\alpha_{t-1})\,x_t + \sqrt{\bar\alpha_{t-1}}\,(1-\alpha_t)\,x_0} {1-\bar\alpha_t}, \] \[ \Sigma_q = \underbrace{\frac{(1-\alpha_t)(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}}_{\sigma_q^2}\, I = \sigma_q^2\, I. \]
Both \(\mu_q\) and \(\Sigma_q\), and therefore \(q(x_{t-1}\mid x_t, x_0)\), are computable and known. \(\mu_q\) is a weighted combination of the current noisy point \(x_t\) and the clean point \(x_0\), and \(\sigma_q^2\) depends only on the fixed schedule \(\alpha_1, \ldots, \alpha_T\).

10. The KL Term Becomes a Regression

We now evaluate

\[ D_{\mathrm{KL}}\!\left(q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\right). \]

Since the true denoising step has a fixed covariance \(\Sigma_q\), we choose the learned step to have the same covariance and only learn its mean:

\[ p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\left(x_{t-1};\ \mu_\theta,\ \Sigma_q\right). \]

The KL divergence between two \(d\)-dimensional Gaussians then becomes

\[ \begin{aligned} &D_{\mathrm{KL}}\!\left[ \mathcal{N}\!\left(x_{t-1};\ \mu_q,\ \Sigma_q\right) \,\|\, \mathcal{N}\!\left(x_{t-1};\ \mu_\theta,\ \Sigma_q\right) \right] \\[6pt] &= \frac{1}{2} \left[ \underbrace{\log\frac{|\Sigma_q|}{|\Sigma_q|}}_{0} - d + \underbrace{\operatorname{tr}\!\left(\Sigma_q^{-1}\Sigma_q\right)}_{\operatorname{tr}(I)\,=\,d} + (\mu_\theta - \mu_q)^\top \underbrace{\Sigma_q^{-1}}_{(\sigma_q^2 I)^{-1}} (\mu_\theta - \mu_q) \right] \\[6pt] &= \frac{1}{2\sigma_q^2}\,\|\mu_\theta - \mu_q\|_2^2. \end{aligned} \]
Denoising matching = regression over \(\mu_q\)
\[ \boxed{ D_{\mathrm{KL}}\!\left(q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\right) = \frac{1}{2\sigma_q^2}\,\|\mu_\theta(x_t) - \mu_q(x_t, x_0)\|_2^2 } \]

11. The ELBO for a DDPM

Dropping the prior matching term (it does not depend on \(\theta\)),

\[ J_\theta(q) = \mathbb{E}_{q(x_1\mid x_0)} \log p_\theta(x_0\mid x_1) - \sum_{t=2}^{T} \mathbb{E}_{q(x_t\mid x_0)} \frac{1}{2\sigma_q^2}\,\|\mu_\theta - \mu_q\|_2^2, \qquad x_T \sim \mathcal{N}(0, I). \]

11.1 Computing the reconstruction term

Consider \(\log p_\theta(x_0\mid x_1)\). We know \(p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\left(x_{t-1};\ \mu_\theta(x_t),\ \Sigma_q\right)\), so for \(t=1\),

\[ p_\theta(x_0\mid x_1) = \mathcal{N}\!\left(x_0;\ \mu_\theta(x_1),\ \sigma_q^2 I\right). \]

Its log-density is

\[ \begin{aligned} \log p_\theta(x_0\mid x_1) &= \log \left[ \frac{1}{(2\pi\sigma_q^2)^{d/2}} \exp\!\left\{-\frac{\|x_0 - \mu_\theta(x_1)\|_2^2}{2\sigma_q^2}\right\} \right] \\[6pt] &= -\frac{\|x_0 - \mu_\theta(x_1)\|_2^2}{2\sigma_q^2} - \underbrace{\frac{d}{2}\log\left(2\pi\sigma_q^2\right)}_{\text{independent of }\theta}. \end{aligned} \]
\[ \Longrightarrow\quad \log p_\theta(x_0\mid x_1) \propto -\frac{\|x_0 - \mu_\theta(x_1)\|_2^2}{2\sigma_q^2}. \]

As in the VAE with a Gaussian decoder, the reconstruction term is a squared error.

The DDPM objective
\[ \boxed{ J_\theta(q) = \mathbb{E}_{q(x_1\mid x_0)} \left[-\|x_0 - \mu_\theta(x_1)\|_2^2\right] - \sum_{t=2}^{T} \mathbb{E}_{q(x_t\mid x_0)} \left[ \frac{1}{2\sigma_q^2}\,\|\mu_\theta(x_t) - \mu_q\|_2^2 \right] } \]
\[ \theta^* = \arg\max_\theta\ J_\theta(q) \]

12. The Denoising Network

The basic idea is to express the unknown \(\mu_\theta(x_t)\) using a function approximator, i.e. a neural network. A U-Net is the usual choice: it first decreases the spatial dimension, then increases it back, so its output has the same shape as its input.

\(x_t,\ t\) input
→
U-Net \(\theta\) decrease dim → increase dim
→
\(\mu_\theta(x_t)\) regressor on \(\mu_q\)

Trained with \(\|\mu_\theta - \mu_q\|_2^2\).

There is one network that predicts \(\mu_\theta(x_t)\) for any \(x_t\), not a separate network per time step. To make sure the network has an idea of “time”, another fixed variable \(t\), corresponding to the time of \(x_t\), is given as input.

12.1 Sinusoidal positional embedding of time

\(t\) is converted into a vector using sinusoidal positional embeddings:

\[ p : t \mapsto \hat{t}, \qquad t \in \mathbb{Z}^+,\ \hat{t} \in \mathbb{R}^d, \] \[ \hat{t}(t)_i = \begin{cases} \sin(\omega_k t) & \text{if } i = 2k \\ \cos(\omega_k t) & \text{if } i = 2k+1 \end{cases} \qquad \omega_k = \frac{1}{10000^{2k/d}}. \]
Why sinusoids? Each pair of coordinates rotates at a different frequency \(\omega_k\), from fast to slow. Nearby time steps get similar vectors, distant ones get different vectors, and the network gets a smooth, informative description of how noisy its input is.

13. ELBO Equivalence: Predicting \(x_0\)

Recall the regression target:

\[ \frac{1}{2\sigma_q^2}\,\|\mu_\theta(x_t) - \mu_q(x_t, x_0)\|_2^2, \qquad \mu_q(x_t, x_0) = \frac{(1-\bar\alpha_{t-1})\sqrt{\alpha_t}}{1-\bar\alpha_t}\,x_t + \frac{(1-\alpha_t)\sqrt{\bar\alpha_{t-1}}}{1-\bar\alpha_t}\,x_0. \]

The network already receives \(x_t\), so the only unknown in \(\mu_q\) is \(x_0\). We therefore give \(\mu_\theta\) the same form, but replace \(x_0\) with a prediction:

\[ \boxed{ \mu_\theta(x_t) = \frac{(1-\bar\alpha_{t-1})\sqrt{\alpha_t}}{1-\bar\alpha_t}\,x_t + \frac{(1-\alpha_t)\sqrt{\bar\alpha_{t-1}}}{1-\bar\alpha_t}\,\hat{x}_\theta(x_t) } \]

where \(\hat{x}_\theta(x_t)\) is the output of a neural network. With this, the \(x_t\) terms cancel:

\[ \begin{aligned} \frac{1}{2\sigma_q^2}\,\|\mu_\theta - \mu_q\|_2^2 &= \frac{1}{2\sigma_q^2} \left\| \frac{(1-\alpha_t)\sqrt{\bar\alpha_{t-1}}}{1-\bar\alpha_t} \left(\hat{x}_\theta(x_t) - x_0\right) \right\|_2^2 \\[6pt] &= \frac{1}{2\sigma_q^2}\, \frac{(1-\alpha_t)^2\,\bar\alpha_{t-1}}{(1-\bar\alpha_t)^2}\, \|\hat{x}_\theta(x_t) - x_0\|_2^2. \end{aligned} \]
Each denoising matching term is a weighted regression onto \(x_0\)
\[ \boxed{ D_{\mathrm{KL}}\!\left(q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\right) \propto \|\hat{x}_\theta(x_t) - x_0\|_2^2 } \]

The reconstruction term fits the same pattern. Since \(\bar\alpha_0 = 1\) and \(\bar\alpha_1 = \alpha_1\), at \(t=1\) the coefficient on \(x_t\) is \(0\) and the coefficient on \(\hat{x}_\theta\) is \(1\), so \(\mu_\theta(x_1) = \hat{x}_\theta(x_1)\) and \(\|x_0 - \mu_\theta(x_1)\|_2^2 = \|\hat{x}_\theta(x_1) - x_0\|_2^2\).

\(x_t,\ t\) noisy input + time
→
U-Net \(\theta\) decrease dim → increase dim
→
\(\hat{x}_\theta(x_t)\) regressor on the input data point \(x_0\)

Trained with \(\|\hat{x}_\theta(x_t) - x_0\|_2^2\).

The network is a denoiser. It can be viewed as a “denoiser” for the data point \(x_0\), at all noisy instances \(x_t\): given a corrupted image and how corrupted it is, guess the clean image.
Contrast with GANs and VAEs: unlike in a GAN or a VAE, the neural network trained in a DDPM does not output a novel data point from \(p_{X}\) (the true data distribution). It only denoises. New samples emerge from running it repeatedly inside the reverse process.

14. Training a DDPM

Given data points \(x_0\) from the true data distribution, with \(T \approx 1000\) and \(\alpha_1, \ldots, \alpha_T \in [0,1]\) fixed:

Algorithm 1 · DDPM training

Repeat until convergence:

  1. Take a data point \(x_0 \sim p_X\).
  2. Pick a time step \(t \sim \mathrm{Uniform}\{1, \ldots, T\}\).
  3. Sample \(x_t \sim q(x_t\mid x_0) = \mathcal{N}\!\left(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)\,I\right)\), i.e. \[ x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon_t, \qquad \epsilon_t \sim \mathcal{N}(0, I). \]
  4. Forward pass: compute \(\hat{x}_\theta(x_t)\) from the U-Net with input \((x_t, t)\).
  5. Backward pass: take a gradient-descent step on the loss \[ \mathcal{L}(\theta) = \sum_{m=1}^{M} \left\|\hat{x}_\theta(x_t^{m}) - x_0\right\|_2^2, \qquad \theta^{k+1} \leftarrow \theta^{k} - \beta\,\nabla_\theta \mathcal{L}(\theta), \] where the sum runs over \(M\) sampled time steps / noisy instances \(x_t^m\) and \(\beta\) is the learning rate.
\(x_t,\ t\) input
→
U-Net \(\theta\) forward pass
→
\(\hat{x}_\theta(x_t)\) prediction
→
\(\nabla_\theta \|\hat{x}_\theta - x_0\|_2^2\) backward pass
Note on weighting: the exact ELBO weighs each time step by \(\frac{1}{2\sigma_q^2}\frac{(1-\alpha_t)^2\bar\alpha_{t-1}}{(1-\bar\alpha_t)^2}\). Training as above drops these weights and uses a plain squared error, which is simpler and works well in practice. Since maximizing the ELBO means minimizing the regression error, we take gradient descent steps on \(\mathcal{L}(\theta)\).

15. Inference / Sampling in a DDPM

To get a sample \(x_0 \sim p_{X}\), we need to traverse the backward / decoding process:

\[ x_T \longrightarrow x_{T-1} \longrightarrow x_{T-2} \longrightarrow \cdots \longrightarrow x_0. \]

That is, we sample iteratively from the decoding distributions \(x_{t-1} \sim p_\theta(x_{t-1}\mid x_t)\) for \(t = T\) down to \(1\):

\[ \begin{aligned} x_T &\sim \mathcal{N}(0, I), \\ x_{T-1} &\sim p_\theta(x_{T-1}\mid x_T), \\ x_{T-2} &\sim p_\theta(x_{T-2}\mid x_{T-1}), \\ &\;\;\vdots \\ x_0 &\sim p_\theta(x_0\mid x_1). \end{aligned} \]

Each step is a Gaussian with the learned mean, so we can sample it with the same reparameterization as in a VAE:

\[ p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\left(x_{t-1};\ \mu_{\theta^*}(x_t),\ \sigma_q^2 I\right) \quad\Longrightarrow\quad x_{t-1} = \mu_{\theta^*}(x_t) + \sigma_q\,\epsilon, \qquad \epsilon \sim \mathcal{N}(0, I), \] \[ \mu_{\theta^*}(x_t) = \frac{(1-\bar\alpha_{t-1})\sqrt{\alpha_t}}{1-\bar\alpha_t}\,x_t + \frac{(1-\alpha_t)\sqrt{\bar\alpha_{t-1}}}{1-\bar\alpha_t}\,\hat{x}_{\theta^*}(x_t). \]
Algorithm 2 · DDPM sampling
  1. Start with \(x_T \sim \mathcal{N}(0, I)\).
  2. For \(t = T, T-1, \ldots, 1\):
    1. Get \(\hat{x}_{\theta^*}(x_t)\) from the trained network (forward pass on \((x_t, t)\)).
    2. Compute \(\mu_{\theta^*}(x_t)\) using the formula above.
    3. Sample \(x_{t-1} = \mu_{\theta^*}(x_t) + \sigma_q\,\epsilon\), \(\epsilon \sim \mathcal{N}(0, I)\), i.e. sample from \(p_\theta(x_{t-1}\mid x_t)\).
  3. Return \(x_0\): a new generated sample.
Sampling is slow: to draw one sample from a DDPM, we need to perform \(T\) forward passes through the trained network \(\theta^*\), one per reverse step. With \(T \approx 1000\), that is far more expensive than the single decoder pass of a VAE or a GAN.

At the last step, \(\sigma_q^2 = \frac{(1-\alpha_1)(1-\bar\alpha_0)}{1-\bar\alpha_1} = 0\) because \(\bar\alpha_0 = 1\), so the final step simply returns the predicted mean without adding noise.

16. Summary

A DDPM follows the same latent-variable recipe as a VAE, with one key change: the encoder is a fixed noising process, so all the learning goes into the decoder.

  1. Hierarchical VAE: \(T\) latent variables \(x_1, \ldots, x_T\), each with the same dimension as the data \(x_0\).
  2. Fixed forward process: \(x_t = \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon_t\), a first-order Markov chain that ends in \(\mathcal{N}(0, I)\).
  3. Learned reverse process: \(p_\theta(x_{t-1}\mid x_t) = \mathcal{N}(\mu_\theta(x_t), \sigma_q^2 I)\), trained by maximizing the ELBO.
  4. Three ELBO terms: reconstruction, prior matching (independent of \(\theta\)), and denoising matching.
  5. Closed forms: \(q(x_t\mid x_0) = \mathcal{N}(\sqrt{\bar\alpha_t}\,x_0, (1-\bar\alpha_t)I)\) and \(q(x_{t-1}\mid x_t, x_0) = \mathcal{N}(\mu_q, \sigma_q^2 I)\) are both known.
  6. KL becomes regression: matching means gives \(\|\mu_\theta - \mu_q\|_2^2\), which, by parameterizing \(\mu_\theta\) through \(\hat{x}_\theta(x_t)\), becomes \(\|\hat{x}_\theta(x_t) - x_0\|_2^2\).
  7. Sampling: start from noise and apply the learned denoiser \(T\) times.
The central DDPM equation
\[ \boxed{ J_\theta(q) = \underbrace{ \mathbb{E}_{q(x_1\mid x_0)} \log p_\theta(x_0\mid x_1) }_{\text{reconstruction}} - \underbrace{ D_{\mathrm{KL}}\!\left(q(x_T\mid x_0)\,\|\,p(x_T)\right) }_{\text{prior matching}} - \sum_{t=2}^{T} \underbrace{ \mathbb{E}_{q(x_t\mid x_0)} D_{\mathrm{KL}}\!\left( q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t) \right) }_{\text{denoising matching}} } \]

Once this equation is understood, the DDPM training loop becomes much less mysterious: noise a data point to a random time step, ask the network to recover the clean data point, and repeat. Generation is that same denoiser, applied \(T\) times to pure noise.
